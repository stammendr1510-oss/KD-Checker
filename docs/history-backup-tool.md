# Проверяемая копия локальной истории

Отдельный инструмент обслуживания, не API приложения. Перед использованием
остановите сервер и обеспечьте отсутствие других писателей. Используйте только
доверенные каталоги: инструмент не защищает от одновременной подмены файлов
другим процессом с правами записи. Не используйте SQLite на сетевом диске.

`python history_backup.py SOURCE NEW_DESTINATION`

Источник открывается read-only. Копируется вся SQLite через backup API,
включая дополнительные таблицы. До и после проверяются integrity_check,
foreign_key_check, версия схемы замечаний 1 и основные столбцы. Существующий
путь назначения всегда отклоняется. При ошибке удаляется только новая копия.
На POSIX новая копия создаётся с правами 0600; на Windows настройте ACL папки.

Для восстановления используйте эту же команду из резервной копии в **новый**
файл и сначала проверьте его в отдельной тестовой установке. Инструмент не
переключает рабочую базу, не меняет config.json и не применяет миграции.
Данные старого формата до управления замечаниями и неизвестные будущие схемы
отклоняются. Совместимость с конкретной версией приложения проверяется отдельно.

Это не шифрование, не расписание резервирования, не доказательство подлинности
копии и не аварийное восстановление предприятия. Копии содержат имена документов,
замечания и комментарии: храните их с соответствующим ограничением доступа.
PR #42/43 остаются независимыми тестами транзакций и восстановления; их код
не скопирован и не требуется для работы инструмента.
