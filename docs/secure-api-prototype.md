# Защищённая фабрика — исполняемый прототип

`create_secure_app(verifier=..., backend=..., sessions=..., origin=...)` создаёт
отдельное приложение. Нет запуска uvicorn, подключения к LAN, импорта local app
или автоматического backend/verifier. Зависимость: PR #44 (policy); ветка
основана на его head. До ручного принятия #44 этот PR не сливать независимо.

Verifier должен обменивать проверенное доказательство входа на Identity,
без доверия user/role/org из HTTP. В тестах — синтетический одноразовый по смыслу
ticket, который fake verifier допускает повторно; это не production login.
Управление реальными паролями, identity provider и MFA не реализованы.

Реализованы индивидуальные случайные cookies __Host-kd_session (Secure,
HttpOnly, SameSite=Strict), серверные записи с хешем токена, абсолютный/idle
timeout, ротация при переавторизации, revoke и logout. CSRF token привязан к
сессии, unsafe операции требуют exact HTTPS Origin и заголовок CSRF. Тела
ошибок валидации не отражают credential. Нет docs/OpenAPI/CORS fallback.

Проверены все 13 существующих операций из PR #38. Объектная проверка до dispatch
требует точное совпадение org/project обоих run и связь finding→run. Текущая
роль извлекается из backend на каждом обращении. Неизвестные роли запрещены.
Неизвестные маршруты/методы не вызывают backend. HTTPS определяется ASGI
transport; доверие пользовательскому X-Forwarded-Proto не добавлено.

Backend — обязательный интерфейс, **не адаптер к глобальной локальной SQLite**.
Он обязан фильтровать lists/config/create по Identity, ограничивать ввод,
транзакционно повторять проверку членства при изменении, выполнять бизнес-логику
и вести audit. Тестовый backend — spy, возвращающий синтетический ответ; он не
означает реализацию обработки KD в защищённом режиме. Нельзя подставить local
app dispatch: у local базы нет tenant scope. Статические страницы не подключены.

Сессии process-local; перезапуск завершает все сессии. Несколько workers,
межпроцессный отзыв, durable sessions, rate limiting login, ограничения тела,
изоляция CPU/RAM и атомарность revoke с уже выполняющимся dispatch не реализованы.
Нужен общий серверный session store и транзакционная граница с репозиторием.
Не принимать этот прототип за готовность G1–G7 или разрешение сетевого запуска.
Локальное приложение и его запуск не меняются. Только искусственные тесты.
