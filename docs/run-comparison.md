# Сравнение двух проверок комплекта КД

Новый read-only API для конструктора: `GET /api/runs/{current_id}/compare/{previous_id}`.
Это первый технический этап пользовательской функции «до/после».
Интерфейс сравнения будет добавлен отдельно после проверки надёжности API.

## Правила сопоставления

- Сравниваются только две уже сохранённые проверки одного списка имён файлов
  (имена нормализуются так же, как для существующего отслеживания замечаний).
- Предыдущая проверка обязана иметь меньший идентификатор.
- **new**: замечание появилось (его точный отпечаток отсутствовал раньше).
- **persisting**: одно замечание точно соответствует одному в предыдущей проверке.
- **disappeared**: замечание больше не обнаружено.
- **ambiguous**: в обеих проверках встретились повторяющиеся идентичные
  замечания; экземпляры невозможно однозначно сопоставить.
- Для сопоставления используется существующая `finding_identity()`, учитывающая
  файл, важность, код, место, текст замечания и рекомендацию. Изменение текста
  может дать пару «исчезло / новое» даже для одной инженерной проблемы.
- Исчезновение замечания **не является доказательством исправления**.
  Различия экспортов PDF и распознавания могут влиять на результаты.
- Статусы, комментарии, решения и история инженера не переносятся
  и не изменяются. База и структура экспорта не мигрируют.

## Пример ответа

```json
{
  "previous_run_id": 4,
  "current_run_id": 5,
  "summary": {"new": 1, "persisting": 2, "disappeared": 1, "ambiguous": 0},
  "new": [{"issue_index": 0, "issue": {"code": "KD-000"}}],
  "persisting": [{"previous": {"issue_index": 1, "issue": {}}, "current": {"issue_index": 2, "issue": {}}}],
  "disappeared": [{"issue_index": 3, "issue": {}}],
  "ambiguous": [],
  "notice": "..."
}
```

Ответ содержит сами замечания для отображения в интерфейсе, но не содержит
прикреплённых PDF. Если набор файлов отличается, API отвечает HTTP 409.
Если указаны несуществующие запуски — HTTP 404; неверный порядок — HTTP 400.

Тесты используют только искусственные записи, не материалы предприятия.
