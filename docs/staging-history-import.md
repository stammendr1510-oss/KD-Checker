# Ограниченный staging-импорт истории

Зависимости: PR #45 (проверенная копия) и PR #55 (scoped repository). Эта ветка
содержит обе зависимости, но не объединяет их с main. Только offline-функция
`stage_history(source, backup, staging, scope=Scope(...), revision=..., operator=...)`.
Нет CLI с рабочими путями, автоматической замены базы или сетевого подключения.

Оператор явно назначает всю исходную историю одной организации/проекту и
редакцию импорта. Не угадывать их по именам. Для смешанной истории предварительно
нужен отдельный reviewed manifest и разделитель, в этом прототипе их нет.

Источник ≤64 МБ копируется через #45. Проверяются структура, FK, fingerprint,
полнота состояний и согласованность всей цепочки audit с текущим решением.
Неизвестные таблицы отклоняются. Известная optional таблица снимков Checklist
архивируется как исходные строки, но не подключается к runtime Checklist.

В новый staging переносятся run IDs/dates/results, решения и версии, даты
событий и их IDs. Actor старых событий — legacy_unknown: оператор импорта не
объявляется их автором. Полные строки всех разрешённых исходных таблиц,
включая fingerprint, previous_id и match_kind отдельных замечаний, сохраняются
в legacy_archive для точной сверки. Нормализованная previous_run связь строится
внутри назначенного scope; per-finding matching пока доступен только в архиве.

Перед commit проверяются counts архива/запусков/состояний/событий, integrity и FK.
Сохраняется SHA256 копии и явный manifest. При ошибке после создания удаляется
только новый staging, проверенная копия остаётся. Существующие файлы назначения
и копии никогда не перезаписываются. Повторный вызов на том же пути отклоняется:
это single-batch import, не resumable/delta importer и не PostgreSQL migration.

Остановите приложение, обеспечьте доверенные каталоги и отсутствие писателей.
Изменения прав на Windows ACL и production cutover не автоматизируются.
Нет доказательства подлинности operator/manifest: функция предназначена только
доверенному оператору, не должна вызываться с пользовательскими HTTP-полями.
Не является production restore или подтверждением G1–G7.
