# Сопоставление обозначений спецификации с файлами комплекта

Проверка `KD-012` ищет обозначение из спецификации как отдельный токен в имени
файла. Это устраняет ложное совпадение короткого номера с более длинным:
`AB.2` не считается найденным в `AB.20` или `XAB.2A`.

Сравнение нечувствительно к регистру и применяет Unicode NFKC для визуально
совместимых вариантов символов. Пунктуация внутри обозначения сравнивается
буквально. Содержимое документов не переписывается. Совпадение имени остаётся
эвристикой комплектности: оно не доказывает, что файл действительно описывает
позицию, и отсутствие совпадения не подтверждает ошибку КД. Стандартные изделия
могут не требовать отдельного файла.

Проверки используют только искусственные записи и локальные строки имён файлов.
Новых пакетов, сетевых запросов, изменений парсеров, Supabase, EPLAN Checklist
или производственных данных нет.
