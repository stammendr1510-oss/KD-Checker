требует их при наличии connection_checks.py из #47, но исходный regex распознавал

каждый код каталога, включая staged коды до появления модуля.

runtime не меняются. Чужая ветка #46 не изменялась. Принимать после #46; перед
подключением #47 выполнить общий набор тестов. Без новых зависимостей и данных.
