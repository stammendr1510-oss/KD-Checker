# Защищённый синтетический импорт соединений

Зависимости #44/52/55/59/60, #47 и #46/57 включены в ветку. Локальный MVP не
изменён. POST /api/connections/check доступен engineer/admin, требует сессию,
Origin/CSRF и Content-Type application/json. Нет native EPLAN и PDF-топологии.

Контракт: schema_version=1 (integer), project, revision, records. В каждой записи
обязательны wire, cable (может быть пустым), source/target с device/terminal,
document и location. Дополнительные поля, дубли JSON-ключей, нечисловые JSON
константы, пропуски и неоднозначные типы отклоняются. До 512 КиБ тела, 1000 записей,
100 документов, 500 символов в строковом поле. Источники — утверждения импортёра,
а не автоматически доказанная достоверность экспорта предприятия.

Организация берётся только из сессии. Project JSON должен точно совпадать с
project сессии. Repo.save повторно проверяет членство в транзакции. KD-CON-101/102
остаются информационными. Run хранит revision, имена документов и findings;
исходный JSON и топология не архивируются. Просмотр/решения/аудит/сравнение и
CSV/XLSX используют существующие защищённые маршруты. Это не сертификация КД.
