# Реальный защищённый тестовый backend

Зависимости #44/#52/#55 включены в ветку; принимать после них. ScopedBackend
не вызывает endpoints локального приложения и не обращается к Checklist.
Повторно использует engine, extractors, PDF pair/full-set и экспорт XLSX.

HTTP finding_id — серверная запись http_findings с FK на точный
org/project/run/ordinal. Пользовательский ordinal не принимается вместо ID.
Репозиторий повторно проверяет членство внутри транзакции записи. Списки,
чтение, сравнение и отчёты ограничены scope. Сессии пока process-local.

Создание проверки принимает multipart files и обязательную revision. Лимиты
100 файлов, 20 МБ на файл, 100 МБ суммарно; ошибки парсера дают KD-000 без деталей.
Исходные документы не сохраняются. Глобальный config.json только читается как
baseline; проектная запись настроек пока явно отклоняется 409. Исторический
Checklist не подключён: соответствующие сравнения дают 409. Нет native EPLAN.

Тесты используют настоящий HTTP, verifier с синтетическими ticket, реальную
временную SQLite, движок, решения, audit и CSV/XLSX. Нет backend-spy.
Изоляция парсеров по CPU/RAM, безопасный production login, общий session store,
редактирование конфигурации и миграции добавочных таблиц ещё требуют работы.
Фабрика не запускает сервер и не открывает LAN. Рабочий local MVP не меняется.
