# Приёмочная матрица истории решений и восстановления scoped-хранилища

Этот пакет тестов основан на PR #55, но **не изменяет его исходный код или ветку**. Работает исключительно с искусственными данными и новой временной SQLite на локальном диске.

## Контракты

- Многошаговое решение инженера образует точную версионную цепочку с первоначальным и конечным статусом, комментариями и идентификатором автора. Устаревшая версия отклоняется без дополнительного события аудита.
- Отзыв членства в проекте A не отзывает независимые разрешения того же субъекта в проекте B и другой организации; чужой run нельзя прочитать через другой scope.
- Проверенная копия базы в **новый файл** сохраняет историю, решения и сравнения запусков, но не снимает ограничения org/project.
- Составные внешние ключи отклоняют попытку привязать событие аудита к run другого проекта; ошибочная транзакция не нарушает ранее существующую историю.
- Проверяются SQLite `integrity_check` и `foreign_key_check`.

## Важные ограничения

Испытание не подтверждает работу на двух компьютерах, PostgreSQL, безопасное многопроцессное хранение токенов, промышленную политику резервирования или корректность реальной КД. Запуск не изменяет действующий `storage.py`, EPLAN Checklist, Supabase или конфигурацию. Копия создаётся из локальной тестовой SQLite без параллельных писателей; это отдельный сценарий от штатной процедуры эксплуатационного backup.

## Запуск

`python -m pytest -q tests/test_scoped_audit_recovery_matrix.py`

Затем полный CI Windows/Linux, ручной анализ конфликтов и проверка после приёма зависимых PR. При открытии PR относительно `main` родительский #55 включён в diff; нельзя объединять тесты до #55.
