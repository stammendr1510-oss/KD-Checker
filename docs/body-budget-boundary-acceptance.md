# Независимая матрица граничных условий ASGI BodyBudget

Набор тестов добавлен поверх Codex PR #69. Не изменяет реализацию BodyBudget, защищённый HTTP backend или локальный MVP. Временная целевая ветка PR — main только ради штатного CI; в diff присутствуют код и коммиты зависимостей.

## Проверяемые контракты

- Тело ровно на пределе 16 байт разрешено, независимо от размера отдельных чанков, включая пустой чанк.
- Превышение на один байт отклоняется до передачи downstream, в том числе когда превышение выявлено только после последнего чанка.
- Для отдельных маршрутов применяются более строгие лимиты, другие маршруты сохраняют общий предел.
- Некорректный, отрицательный или завышенный Content-Length не допускает передачу дальше.
- Несовпадение заявленного и фактического размера отклоняется.
- Пустое тело с заявленным Content-Length 0 обрабатывается корректно.
- SpooledTemporaryFile закрывается при переполнении и несовпадении длины даже после переноса содержимого на диск.

Запуск: `python -m pytest -q tests/test_body_budget_boundary_matrix.py`; затем полный набор CI Windows/Linux.

**Ограничения:** отдельные ASGI тесты не доказывают устойчивость к произвольной нагрузке, ограничение суммарного диска всех запросов, CPU/RAM изоляцию парсеров, производственный reverse proxy/TLS, безопасность физической сети или эксплуатацию на двух ПК. Не выполнять большие реальные запросы, не подключать платные сервисы и не использовать рабочую КД.

Принимать только после PR #69 и зависимостей; не сливать автоматически.
