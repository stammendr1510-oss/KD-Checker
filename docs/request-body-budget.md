# Ограниченный приём тела защищённого запроса

Зависит от #68 и предыдущих блоков. Только защищённая фабрика; local app не меняется.
BodyBudget принимает тело до JSON/multipart parser. Общий предел 105 МиБ включает
multipart overhead; connections — 512 КиБ, login — 8 КиБ, config — 64 КиБ.
Фабрика допускает уменьшенные лимиты и receive deadline для синтетических тестов.

Content-Length проверяется заранее и сверяется с фактическим телом. Chunked/без
Content-Length тоже ограничены. Превышение — 413, несогласованная длина — 400,
истечение общего времени получения тела (по умолчанию 30 с) — 408. Гость
отклоняется внешней auth-границей до буферизации.

До 256 КиБ в памяти, затем unnamed SpooledTemporaryFile в системном temp;
context manager закрывает его при отказе, исключении и завершении. После приёма
тело переигрывается парсеру чанками. Multipart может создать свои временные
файлы: суммарное дисковое потребление включает оба слоя и не является глобальной
квотой. Нужны доверенный temp, ACL, ограничения concurrent requests и диска ОС.
ASGI-сервер может уже выделить память для одного входящего чанка: этот слой не
заменяет transport/reverse proxy limits. Нет production deployment.

Receive deadline не ограничивает CPU/time PDF/DXF/Excel парсера. Для этого
нужен отдельный killable worker с бюджетами ОС и переносимыми тестами; данный
PR не объявляет такую изоляцию реализованной. Таймаут потока не используется.
Тесты используют байты/миллисекунды и реальный защищённый API, не большие файлы.
