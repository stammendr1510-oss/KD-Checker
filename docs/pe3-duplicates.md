# Повторяющиеся обозначения ПЭ3

## Область и код

`KD-PE-104` — предупреждение о достоверно распознанном повторе одного нормализованного
обозначения в разных строках **одного загруженного PDF ПЭ3**. Проверка выполняется
и без парного Э3. Документ распознаётся по существующему обозначению `.ПЭ3` в имени.

`KD-PE-103` не переиспользуется: он уже занят проверкой похожих алфавитов в Э3.
KD-PE-102 и остальные инженерные проверки сохраняют прежнее назначение.

Разные загруженные ПЭ3 не объединяются, даже если относятся к похожему комплекту
или содержат одинаковые обозначения. Содержание Э3 не участвует в поиске дублей.
Границы разных документов внутри одного объединённого PDF не распознаются:
каждый ПЭ3 следует загружать отдельным файлом, который и задаёт область проверки.
При нескольких Э3, сопоставленных одному ПЭ3, проверка дублей выполняется один раз
для этого загруженного ПЭ3, а прежняя сверка пар остаётся самостоятельной.

## Какие повторы находятся

- Одинаковые одиночные обозначения в разных строках одной страницы.
- Одинаковые обозначения на разных страницах одного ПЭ3.
- Пересечение двух явно заданных диапазонов в разных строках.
- Обозначение из диапазона, явно присутствующее в другой строке отдельно или
  в списке с разделителем `;`.

Используется существующий разбор диапазонов, переносов, регистра и похожих
латинских/кириллических букв. Новые обозначения не выводятся из количества.
Список предупреждений упорядочен по нормализованным обозначениям; для каждого
обозначения выдаётся одно предупреждение со всеми установленными местами.

## Условия достоверности и исключения

Новый детектор использует только строки существующего координатного извлекателя:
столбец позиционных обозначений и распознанное количество. Дополнительно обязательны
две горизонтальные и две вертикальные границы узкой ячейки обозначений, заданные
линиями PDF, и ровно одна привязка количества внутри её горизонтального интервала. Фоновые
заливки не считаются границами. Все извлечённые слова должны целиком помещаться
в позиционном столбце; пропущенные слова внутри ячейки исключают кандидата.
Должна быть полностью распознана вся запись обозначений: строки с `unknown`
исключаются целиком, даже если их отдельные части понятны. Верхняя область
заголовков до 50 PDF-пунктов не считается строками данных.

Диапазоны с ведущими нулями в номерах исключаются из доказательства дубля:
существующий раскрывающий парсер преобразует номера в целые числа, поэтому
`1KM01...1KM03` нельзя безопасно приравнять к отдельной записи `1KM1`.
Сам парсер и прежние проверки при этом не меняются. Одиночные `1KM01` и
`1KM01` в разных достоверных ячейках остаются точным повтором.

Ячейка идентифицируется страницей и её вертикальными границами. Повторная запись
одной ячейки в результатах извлечения не создаёт вторую строку. Внутри одной
ячейки обозначение учитывается один раз; повторное упоминание, пересекающиеся
части одной записи или раскрытие одного диапазона сами по себе не дают KD-PE-104.

Текст заголовков, описаний и примечаний не сканируется как область обозначений.
Если описание попало в прежнее фиксированное окно извлечения, но находится за
вертикальной границей позиционного столбца, для дублей такая строка исключается.
Общая рамка вокруг нескольких строк не заменяет разделители строк. Без надёжной
сетки таблицы новый детектор пропускает кандидатов; прежнее эвристическое
извлечение для сверки Э3/ПЭ3 при этом продолжает работать.

## Как читать предупреждение

Указывается имя PDF, обозначение и все установленные страницы/строки.
«Лист» означает порядковую страницу PDF. Номер строки вычислен по горизонтальным
линиям, включая заголовок и пустые интервалы; это **не напечатанный номер позиции**
и не распознавание основной надписи. При необычной рамке порядковый номер следует
сверить с исходной таблицей.

Предупреждение подтверждает повтор текста в нескольких ячейках, а не инженерную
ошибку. Продолжение записи, повторное указание колодки для других контактов или
особенности комплектования могут быть допустимыми. Инженеру предлагается сравнить
исходные ячейки, затем самостоятельно выбрать решение и при необходимости
добавить обоснование. Автоматического исправления КД или закрытия замечания нет.

## Ограничения и совместимость

Сохраняются ограничения координатного извлекателя: поддерживаемая вёрстка,
текстовый слой, распознанное количество и область страницы выше 83% её высоты.
Неподдерживаемые и обрезанные строки, необычные заголовки, сканы без OCR,
неоднозначные символы и таблицы без сетки могут дать пропуски. Отсутствие
KD-PE-104 не подтверждает отсутствие всех дублей или соответствие КД нормативам.

Новая проверка не меняет уникальный состав ПЭ3 или результаты сопоставления с Э3.
Она добавляет отдельные предупреждения к существующим результатам API.
Состояния инженера, журнал, повторные проверки, CSV и Excel используют прежний
формат замечания. Новые появления, как и раньше, имеют статус «Новое»; прежнее
«Устранено» не переносится автоматически. Формат SQLite не изменён, миграция
после версии с PR №5 не требуется. История старых проверок не пересчитывается.

Тесты используют только искусственные PDF. Сценарий с 64 совпадениями и KD-PE-102
для количества 9 против 7 обозначений проверяется через API с новым детектором.
Исходные документы предприятия и их координатные выгрузки в репозиторий не входят.
