# Независимые регрессии защищённого HTTP-пайплайна

Зависит от PR #44 → #52 → #55 → #59 → #60. Ветка основана на #60 и не изменяет его исходники. При открытии PR на `main` наследуемые файлы родителей будут видны в diff; принимать только после зависимостей.

Синтетические HTTP-сценарии работают с `ScopedBackend`, `Repository`, настоящей FastAPI-фабрикой и временными SQLite. Нет backend-spy, сети предприятия, паролей или рабочих КД.

## Сценарии

1. Повышенные полномочия инженера отзываются путём изменения текущего членства. Существующий cookie не даёт редактировать/создавать, но новое право viewer допускает чтение; audit и version не меняются.
2. Полный отзыв членства после login запрещает чтение, список, CSV/XLSX, не удаляя историю.
3. Неподключённые Checklist comparison API явно возвращают 409, обычная пара KD-run сравнивается, отсутствуют скрытые audit-побочные эффекты.
4. Logout аннулирует cookie, новая сессия не наследует прошлое решение инженера; сохранённое решение и инертный формульный текст в XLSX остаются доступными авторизованному инженеру.

Это не production verifier, TLS/reverse proxy, PostgreSQL, нагрузочные испытания, runtime-оценка ГОСТ или физическая двухкомпьютерная приёмка. Никакой backend-адаптер и работающий local MVP не изменены.

Запуск целевого набора: `python -m pytest -q tests/test_secure_backend_transition_regressions.py`.

После этого — общий Windows/Linux CI, независимая проверка совместимости с #58 и только ручное слияние в правильном порядке.
