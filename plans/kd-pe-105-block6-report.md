## 8. Оставшиеся технические ограничения

1. Реальные `ТНБВ.656451.162.Э3/ПЭ3` и `kd-report-1 (1)(1).xlsx` недоступны.
   Сравнение «до/после» на реальных данных не выполнено.
2. Windows 11 не запускался. `950 passed, 5 skipped` из постановки в этом
   окружении не воспроизводимы; независимый Linux-прогон даёт `1080 passed,
   1 skipped`.
3. Классификация `X`: слой классификации помечает одиночный `X1` как
   `ambiguous`, но агрегация при `kind=label` оставляет его info-кандидатом
   `no_matching_pe3_row`. Warning при этом невозможен. Это осознанно не
   менялось в блоке 6, чтобы не alter-ить поведение реального отчёта без
   данных; ограничение зафиксировано для решения по блоку 7.
4. KD-PE-105 — текстовое сопоставление, не OCR и не доказательство
   физического отсутствия элемента.
5. Извлечение и классификация эвристические; представление делает их
   ограничения явными, но не устраняет.
6. Windows Job Object, ACL и `msvcrt.locking` реализованы, но на Linux не
   выполнялись; соответствующий тест пропущен.
7. GitHub Actions запускается только на `pull_request` в `main`; stacked PR
   в `feature/e3-pe3-missing-designations` его не запускает. Прямой GitHub push
   недоступен без токена, поэтому публикация выполнена безопасным механизмом
   SourceCraft (Draft PR, без merge).
8. Человекочитаемый Excel ограничен 20 обозначениями; полный список хранится
   в JSON-колонке (до 30 000 символов).
9. Отчёт не является аттестацией ЕСКД/ГОСТ и не заменяет инженерную приёмку.

## 9. Инструкция для Windows 11

Полная пошаговая инструкция: [`docs/kd-pe-105-windows-acceptance.md`](../docs/kd-pe-105-windows-acceptance.md).

Кратко:

1. Отдельная тестовая папка, Python 3.13, venv, зависимости, Chromium.
2. `git checkout feature/kd-pe-105-acceptance`, чистое рабочее дерево.
3. `python tools/dependency_policy.py`.
4. Целевые тесты KD-PE-105, совместимость, PDF/парсеры, Excel/CSV/история,
   затем полный `python -m pytest -q`.
5. `python synthetic_stand.py accept --synthetic-only --workspace .\acceptance-stand`.
6. Реальные Э3/ПЭ3 — только из папки вне репозитория, через локальный
   `start_windows.bat`; выгрузки XLSX/CSV также вне репозитория.
7. Заполнить протокол: TA (`3TA2`/`3TA3`), KM (info, не warning), X/XT
   (не изделие без контекста), 6 колонок CSV, 10/12 колонок Excel, история
   решений.
8. Не публиковать реальные PDF, XLSX, персональные данные и секреты.
